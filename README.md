# [중간고사]퍼블리싱 성장 서비스 - 연습 과제 설정

## 배포 주소

- 웹페이지: https://hyehyewon2.github.io/uiuxprogramming/
- 저장소: https://github.com/hyehyewon2/uiuxprogramming.git

## 서비스 소개

- 사용자: 퍼블리싱을 처음 배우고 있어 성장해 나아가고 싶은 초보 퍼블리셔
- 서비스 목적: 실제 프로젝트와 비슷한 과제를 반복해서 연습하면서 퍼블리싱 실력과 자신감을 키울 수 있게 돕는다.
- 사용자 목표: 연습할 과제를 정하고 연습 시간과 AI 코드 리뷰 여부를 골라서 연습을 준비한다.
- 핵심 행동: 연습 과제 설정하기
- 완료 조건: 과제 제목을 입력하고 해당 조건을 선택한 다음 확인 화면에서 "설정 완료하기"를 클릭하면 완료 화면이 표출된다.

## 새로 추가한 기능 - 내 코드 접근성 점검

7주차에는 연습 과제 설정이 완료되면 끝났지만 완료 화면에서 바로 "접근성 점검하기"로 이어지게 만들었다. 연습한 코드에서 지킨 접근성 항목을 체크하면 몇 개를 통과했는지 보여 주고 체크하지 않은 항목은 어떤식으로 수정해야하는지 알려 준다.

- 연결 지점: 7주차 흐름의 끝(설정 완료 화면)에 "접근성 점검하기" 버튼을 추가했다.
- 점검 화면에는 7주차 1단계에서 입력한 과제 제목이 같이 나온다.

## 사용자 흐름

### 연습 과제 설정 (7주차)

1. 연습 준비 설정에서 코드 분석 동의에 체크하고 "연습 설정 시작하기"를 누른다.
2. 코드 분석 안내 창이 뜨면 "동의하고 설정 시작하기"를 누른다. "돌아가기"를 누르면 동의가 풀리고 처음으로 돌아간다.
3. 1단계(정보)에서 과제 제목을 입력한다. 제목을 안 쓰면 다음 단계로 못 넘어가고 안내 문구가 나온다.
4. 2단계(조건)에서 연습 시간(30분, 60분, 90분)을 고르고 원하면 AI 코드 리뷰를 체크해서 리뷰 개수(1~3개)를 고른다.
5. 3단계(확인)에서 내가 입력한 내용이 맞는지 확인한다. 바꾸고 싶으면 "수정하기"를 눌러 2단계로 돌아간다.
6. "설정 완료하기"를 누르면 완료 화면이 나오고 "다시 설정하기"를 누르면 처음부터 다시 할 수 있다.

### 접근성 점검 (중간고사 추가)

7. 완료 화면에서 "접근성 점검하기"를 누르면 연습한 코드의 웹 접근성을 점검할 수 있다.

## 인터랙션 시나리오

### 접근성 점검 (중간고사 추가)

1. 점검 열기
   - 행동: 완료 화면에서 "접근성 점검하기"를 누른다.
   - 조건: 없음 (설정을 완료해야 버튼이 보인다)
   - 반응: 점검 영역이 열리고 과제 제목이 표시되며 첫 번째 체크 항목으로 커서가 간다.
   - 다음 행동: 지킨 항목에 체크하기
2. 점검 결과 보기
   - 행동: 항목을 체크하고 "점검 결과 보기"를 누른다.
   - 조건: 체크한 개수가 0개인지, 전부(4개)인지, 일부인지
   - 성공 반응: 4개 모두 체크하면 "4 / 4 축하드립니다! 접근성 기본 점검이 통과되었습니다!^__^" 라는 문구가 표출된다.
   - 일부 통과 반응: "2 / 4 통과되었습니다. 아래 내용을 확인하고 수정해 주세요." 처럼 나오고 체크하지 않은 항목의 해결 방법을 하단에 보여 준다.
   - 오류 반응: 하나도 체크하지 않으면 "확인한 항목에 하나 이상 체크해 주세요." 가 나오고 결과는 보여 주지 않는다.
   - 다음 행동: 코드를 고친 뒤 다시 체크하거나 다시 점검하기
3. 다시 점검하기
   - 행동: "다시 점검하기"를 누른다.
   - 조건: 없음
   - 반응: 체크, 오류 문구, 결과가 모두 처음 상태로 돌아간다.
   - 다음 행동: 처음부터 다시 체크하고 결과 보기
4. 점검 닫기 (취소)
   - 행동: "점검 닫기"를 누른다.
   - 조건: 없음
   - 반응: 점검 영역만 닫히고 다시 열면 체크했던 항목이 그대로 남아 있다.
   - 다음 행동: 완료 화면에서 "접근성 점검하기"를 눌러 이어서 점검하기
5. 새 연습 설정하기
   - 행동: "새 연습 설정하기"를 누른다.
   - 조건: 없음
   - 반응: "다시 설정하기"처럼 설정 값이 초기화되고 접근성 점검도 같이 초기화된 다음 1단계로 이동한다.
   - 다음 행동: 새 과제 제목을 입력하고 다시 설정하기

### 연습 과제 설정 (7주차)

1. 동의 체크
   - 행동: 코드 분석 동의에 체크한다.
   - 이벤트: change
   - 조건: 체크가 되어 있는지
   - 화면 반응: 체크하면 "연습 설정 시작하기" 버튼이 활성화되고 체크를 풀면 다시 비활성화된다.
   - 다음 상태: 시작 버튼을 누를 수 있는 상태

2. 설정 시작
   - 행동: "연습 설정 시작하기"를 누른다.
   - 이벤트: click
   - 조건: 동의에 체크했는지
   - 화면 반응: 코드 분석 안내 창이 열린다.
   - 다음 상태: 안내 창에서 동의하거나 돌아가기를 고르는 상태

3. 안내 창에서 돌아가기
   - 행동: "돌아가기"를 누르거나 Esc를 누른다.
   - 이벤트: click, cancel
   - 조건: 없음
   - 화면 반응: 창이 닫히고 동의 체크가 풀리며 시작 버튼이 비활성화된다.
   - 다음 상태: 처음 상태 (다시 동의해야 시작 가능)

4. 안내 창에서 동의
   - 행동: "동의하고 설정 시작하기"를 누른다.
   - 이벤트: click
   - 조건: 동의에 체크했는지
   - 화면 반응: 창이 닫히고 설정 영역이 열리며 제목 입력칸으로 커서가 간다.
   - 다음 상태: 1단계(정보)

5. 제목 입력 후 다음
   - 행동: "연습 조건 선택하기"를 누른다.
   - 이벤트: click
   - 조건: 제목이 비어 있는지 (trim()으로 띄어쓰기만 넣은 것도 빈 값으로 처리)
   - 화면 반응: 비어 있으면 "과제 제목을 입력해 주세요." 문구와 빨간 테두리가 나오고 입력칸으로 커서가 간다. 제목이 있으면 오류 표시가 사라진다.
   - 다음 상태: 비어 있으면 1단계에 머물고 제목이 있으면 2단계(조건)로 이동

6. 연습 시간 선택
   - 행동: 슬라이더를 움직인다.
   - 이벤트: input
   - 조건: 슬라이더 값(0, 1, 2)
   - 화면 반응: 옆에 30분, 60분, 90분 중 하나가 표시된다.
   - 다음 상태: 2단계에 머문다.

7. AI 코드 리뷰 선택
   - 행동: "AI 코드 리뷰 포함"을 체크하거나 해제한다.
   - 이벤트: change
   - 조건: 체크가 되어 있는지
   - 화면 반응: 체크하면 리뷰 개수(1개, 2개, 3개)를 고르는 부분이 보이고 해제하면 숨겨진다.
   - 다음 상태: 2단계에 머문다.

8. 이전 단계로
   - 행동: 2단계에서 "이전"을 누른다.
   - 이벤트: click
   - 조건: 없음
   - 화면 반응: 1단계가 보이고 입력했던 제목이 그대로 남아 있다.
   - 다음 상태: 1단계(정보)

9. 내용 확인
   - 행동: "내용 확인하기"를 누른다.
   - 이벤트: click
   - 조건: 없음 (선택한 값을 formData에 저장)
   - 화면 반응: 확인 화면에 과제 제목, 연습 시간, 코드 리뷰 여부가 표시된다.
   - 다음 상태: 3단계(확인)

10. 수정하기
    - 행동: 3단계에서 "수정하기"를 누른다.
    - 이벤트: click
    - 조건: 없음
    - 화면 반응: 2단계가 보이고 이전에 골랐던 시간과 리뷰 선택이 그대로 남아 있다.
    - 다음 상태: 2단계(조건)

11. 설정 완료
    - 행동: "설정 완료하기"를 누른다.
    - 이벤트: click
    - 조건: 없음
    - 화면 반응: "연습 설정이 완료되었습니다." 완료 화면이 나온다.
    - 다음 상태: 완료
    
12. 다시 설정하기
    - 행동: 완료 화면에서 "다시 설정하기"를 누른다.
    - 이벤트: click
    - 조건: 없음
    - 화면 반응: 제목, 오류 표시, 연습 시간, 리뷰 선택, 확인 내용이 모두 처음 값으로 돌아간다.
    - 다음 상태: 1단계(정보)

## 테스트 결과

크롬에서 직접 하나하나 클릭해가며 확인해보았다.

### 접근성 점검 (중간고사 추가)

1. 정상 흐름 (전부 통과)
   - 과제 제목 "로그인 폼"으로 설정을 완료하고 "접근성 점검하기"를 눌렀다.
   - 점검 화면에 "로그인 폼" 과제의 코드를 점검합니다.가 나왔다.
   - 4개를 모두 체크하고 결과를 보니 "4 / 4 축하드립니다! 접근성 기본 점검이 통과되었습니다!^__^"가 나오고 해결 방법은 나오지 않았다.
2. 일부 통과
   - 이미지 alt, 제목 태그 순서 2개만 체크하고 결과를 보니 "2 / 4 통과되었습니다. 아래 내용을 확인하고 수정해 주세요."가 나왔다.
   - 체크하지 않은 label, 버튼 텍스트 항목의 해결 방법 2개만 보였다.
3. 오류 (아무것도 체크 안 함)
   - 체크 없이 결과 보기를 누르니 "확인한 항목에 하나 이상 체크해 주세요."가 나오고 결과 영역은 나오지 않았다.
4. 취소 (점검 닫기)
   - 4개 체크한 상태에서 닫았다가 다시 여니 4개가 그대로 체크되어 있었다.
5. 다시 점검하기
   - 누르니 체크가 모두 풀리고 결과와 문구가 사라졌다.
6. 새 연습 설정하기
   - 누르니 1단계로 돌아가고 제목 칸이 비어 있었으며 접근성 점검 체크도 초기화되었다.
   - 새 제목 "카드 UI"로 다시 설정을 완료하고 점검을 여니 "카드 UI" 과제의 코드를 점검합니다.로 바뀌어 나왔다.
7. 모바일 (390px)
   - 점검 버튼들이 세로로 쌓이고 체크 항목과 결과가 화면 밖으로 밀리거나 겹치지 않았다.
   - 가로 스크롤도 생기지 않았다.

### 연습 과제 설정 (7주차)

1. 정상 흐름
   - 제목에 "로그인 폼"을 쓰고 30분, AI 코드 리뷰 1개를 골라서 확인했다.
   - 확인 화면에 "로그인 폼 / 30분 / 1개 포함"이 잘 나왔고 완료 버튼을 누르니 완료 화면이 나왔다.
2. 안내 창에서 취소
   - "돌아가기"를 누르니 창이 닫히고 동의 체크가 풀렸다.
   - 시작 버튼도 다시 비활성화되었다.
3. 제목을 안 썼을 때
   - 제목 없이 다음 버튼을 누르니 1단계에 그대로 있고 안내 문구랑 빨간 테두리가 나왔다.
   - 띄어쓰기만 넣었을 때도 똑같이 안내 문구가 나왔다.
   - 제목을 쓰고 다시 누르니 오류 표시가 없어지고 2단계로 넘어갔다.
4. 이전 단계로 돌아가기
   - 2단계에서 "이전"을 누르니 1단계로 돌아갔고 제목이 그대로 남아 있었다.
   - 3단계에서 "수정하기"를 누르니 2단계에서 골랐던 30분, 리뷰 1개가 그대로 있었다.
   - 시간을 90분으로 바꾸고 다시 확인하니 90분으로 바뀌어 표시되었다.
5. 다시 설정하기
   - 완료 화면에서 "다시 설정하기"를 누르니 1단계로 돌아갔다.
   - 제목은 비어 있고 시간은 60분, 리뷰는 체크 해제, 리뷰 개수는 2개로 처음 상태로 돌아가 있었다.
6. 모바일 (390px)
   - 안내 창이 화면 안에 잘 들어오고 버튼들이 세로로 쌓여서 누르기 편했다.
   - 1~3단계 모두 가로 스크롤이 생기지 않았고 버튼이나 입력칸이 화면 밖으로 밀리지 않았다.
