## 6주차 이벤트와 탭 UI 추가

### 확인할 문제

화면 테마, 닉네임 입력, 동의 체크, 성장기능 탭을 조작해도 화면에 아무 변화가 없는 점

### 수정한 내용

- 테마 버튼을 클릭하면 body에 dark 클래스를 토글하고 버튼 글자를 바꾸었다.
- 닉네임을 입력할 때 input 이벤트로 글자 수를 "0 / 10" 형식으로 보여주었다.
- 동의 체크박스의 change 이벤트로 연습 시작 버튼의 disabled와 안내 메시지를 바꾸었다.
- 성장기능 영역을 tablist, tab, tabpanel 역할을 가진 탭 UI로 변경했다.
- 탭을 클릭하면 모든 탭과 패널을 초기화한 뒤, 클릭한 탭과 연결된 패널만 보여주었다.
- 선택한 탭에 is-active 클래스와 aria-selected="true"를 적용했다.
- 다크 테마에서 카드, 탭, 패널의 색상을 함께 바꾸었다.

### 확인할 동작과 실제 결과

| 확인할 동작 | 조작 | 실제 결과 |
|---|---|---|
| 테마 전환 | 테마 버튼 클릭 → 다시 클릭 | 첫 클릭에 배경이 어두운 색으로 바뀌고 버튼이 "라이트 테마로 바꾸기"로 바뀜. 다시 클릭하면 원래 화면과 "다크 테마로 바꾸기"로 돌아옴 |
| 닉네임 글자 수 표시 | 3글자 입력 → 10글자 입력 → 모두 지움 | "3 / 10" → "10 / 10" → "0 / 10"으로 바뀜. 10글자를 넘게 입력되지 않음 |
| 동의 후 버튼 활성화 | 체크 → 체크 해제 | 처음에는 버튼이 비활성화됨. 체크하면 버튼이 활성화되고 "연습을 시작할 수 있습니다"가 표시됨. 해제하면 다시 비활성화되고 "동의 후 연습을 시작할 수 있습니다."로 돌아옴 |
| 탭 전환 | 두 번째 → 세 번째 → 첫 번째 탭 클릭 | 클릭한 탭에만 is-active와 aria-selected="true"가 적용되고, 연결된 패널 하나만 보임 |
| 이메일 신청 (5주차) | 빈 값으로 신청 → 이메일 입력 후 신청 | 빈 값이면 안내 문구가 나오고 입력창에 focus됨. 입력 후 신청하면 "test@example.com로 신청이 완료되었습니다." 표시, 버튼이 "신청 완료"로 바뀌고 비활성화됨 |

### 세 너비별 화면·기능 확인 결과

| 너비 | 화면 배치 | 기능 확인 |
|---|---|---|
| 1100px | 메뉴와 탭 버튼이 가로 한 줄로 배치됨. 연습 준비 카드 3개가 한 줄에 3열로 배치됨. 이메일 입력창과 신청 버튼이 가로로 나란히 배치됨 | 테마 전환, 글자 수 표시, 동의 후 버튼 활성화, 탭 전환, 이메일 신청 모두 정상 동작 |
| 768px | 메뉴와 탭 버튼이 세로 한 열로 바뀌고 탭 버튼이 가로 폭을 꽉 채움. 연습 준비 카드는 2열(2개 + 1개)로 배치됨. 이메일 입력창과 버튼이 세로로 쌓임 | 모두 정상 동작 |
| 390px | 메뉴, 탭 버튼, 연습 준비 카드, 이메일 폼이 모두 한 열로 배치됨 | 모두 정상 동작 |

- 세 너비 모두 가로 스크롤이 생기지 않았다.
- 버튼과 입력창이 화면 밖으로 밀리거나 카드끼리 겹치지 않았다.
