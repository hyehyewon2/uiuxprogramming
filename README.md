## 5주차 JavaScript 인터랙션 추가

### 확인할 문제

이메일 폼에서 신청 버튼을 눌러도 아무 반응이 없었다.

### 수정한 내용

- form, input, button, 메시지 요소에 id를 추가하고 script.js를 연결했다.
- querySelector로 폼, 이메일 입력창, 버튼, 메시지 요소를 선택했다.
- submit 이벤트에서 preventDefault로 페이지 새로고침을 막았다.
- 이메일이 비어 있으면 안내 메시지를 보여주고 입력창에 focus를 주었다.
- 신청에 성공하면 완료 메시지를 보여주고 is-success 클래스를 추가했다.
- 신청 후 버튼 글자를 "신청 완료"로 바꾸고 disabled로 비활성화했다.

### 확인할 동작

빈 값으로 신청 / 이메일 입력 후 신청 / 신청 후 버튼 비활성화
