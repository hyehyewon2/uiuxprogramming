# [9주차 실습] 퍼블리싱 성장 서비스 - 연습 계획 만들기

퍼블리싱 연습 계획을 만드는 폼에 이번 주에 배운 폼 검증과 제출 처리를 넣어 봤습니다.

## 서비스 소개

- 사용자: 퍼블리싱을 처음 배우면서 실력을 키우고 싶은 초보 퍼블리셔
- 서비스 목적: 연습할 과제와 조건을 정해서 계획을 저장해 두고 다시 볼 수 있게 합니다.
- 사용자 목표: 과제 정보, 연습 시간, AI 코드 리뷰 여부를 정해서 연습 계획을 만듭니다.
- 핵심 행동: 연습 계획 저장하기
- 완료 조건: 과제 제목을 입력하고 조건을 고른 다음 확인 화면에서 "계획 저장하기"를 누르면 완료 화면이 나오고 내 계획 목록에 추가됩니다.

## 이번 주에 추가한 것

이전에는 제목이 비어 있는지만 확인하고 버튼을 누르면 바로 저장됐는데, 이번에는 입력하는 동안 상태가 보이게 하고 저장도 form의 submit 이벤트로 처리하게 바꿨습니다.

- 제목 글자 수와 조건을 만족했는지가 입력하는 동안 바로 보입니다. 색만 바뀌면 알아보기 어려워서 문구도 같이 바뀌게 했습니다.
- 제목이 비어 있거나 띄어쓰기만 있거나 1자면 오류 문구가 나오고, 고치면 바로 사라집니다.
- AI 코드 리뷰를 체크해야 리뷰 항목 수를 고르는 부분이 나오고, 체크를 풀면 숨겨지면서 라디오 버튼도 disabled 됩니다.
- 저장하는 동안에는 버튼을 막아서 두 번 저장되지 않게 했습니다.
- 저장에 실패해도 입력한 내용은 그대로 남아 있어서 다시 시도할 수 있습니다.
- "새 계획 만들기"를 누르면 입력값과 안내 문구, 버튼 상태까지 전부 처음으로 돌아갑니다.

## 입력 조건

- 과제 제목: 필수, 공백 빼고 2자 이상 60자 이하
- 학습자 이름: 선택, 10자 이하
- 연습 시간: 3분, 5분, 10분 중 선택 (기본 5분)
- AI 코드 리뷰: 선택
- 리뷰 항목 수: AI 코드 리뷰를 체크했을 때만 1~3개 중 선택 (기본 2개)

## 사용자 흐름

1. 1단계에서 과제 제목과 이름을 입력합니다. 제목이 조건에 맞지 않으면 다음으로 넘어가지 않습니다.
2. 2단계에서 연습 시간을 고르고, 원하면 AI 코드 리뷰를 체크해서 리뷰 항목 수를 고릅니다.
3. 3단계에서 입력한 내용을 확인합니다. "정보 수정"이나 "조건 수정"으로 돌아가서 고칠 수 있습니다.
4. "계획 저장하기"를 누르면 잠깐 저장 중 문구가 나오고 완료 화면으로 넘어갑니다.
5. "새 계획 만들기"를 누르면 처음부터 다시 작성할 수 있습니다.

## 인터랙션 시나리오

1. 제목 입력
   - 행동: 과제 제목 입력
   - 이벤트: input
   - 조건: 공백 빼고 2자 이상인지
   - 화면 반응: 글자 수가 바뀌고, 2자 이상이면 초록색 표시와 함께 "입력 조건을 충족했습니다."가 나옵니다.
   - 다음 상태: 1단계 유지

2. 다음 단계로
   - 행동: "연습 조건 선택하기" 클릭 또는 Enter
   - 이벤트: click, submit
   - 조건: 제목이 비어 있는지, 1자인지 (trim()으로 띄어쓰기만 넣은 것도 빈 값 처리)
   - 화면 반응: 비어 있으면 "과제 제목을 입력해 주세요.", 1자면 "과제 제목은 2자 이상 입력해 주세요."가 빨간 테두리와 같이 나옵니다.
   - 다음 상태: 조건에 맞으면 2단계, 아니면 1단계 유지

3. 오류 고치기
   - 행동: 오류가 난 제목 수정
   - 이벤트: input
   - 조건: 고친 제목이 조건에 맞는지
   - 화면 반응: 조건에 맞으면 오류 문구와 빨간 테두리가 없어집니다.
   - 다음 상태: 다음 단계로 이동 가능

4. AI 코드 리뷰 선택
   - 행동: "AI 코드 리뷰도 받을게요" 체크 또는 해제
   - 이벤트: change
   - 조건: 체크 여부
   - 화면 반응: 체크하면 리뷰 항목 수 선택이 보이고, 해제하면 숨겨지면서 disabled 됩니다.
   - 다음 상태: 2단계 유지

5. 이전, 수정하기
   - 행동: "이전 단계", "정보 수정", "조건 수정" 클릭
   - 이벤트: click
   - 조건: 없음
   - 화면 반응: 해당 단계로 돌아가고 입력했던 값은 그대로 남아 있습니다.
   - 다음 상태: 1단계 또는 2단계

6. 내용 확인
   - 행동: "내용 확인하기" 클릭
   - 이벤트: click
   - 조건: 없음
   - 화면 반응: 과제 제목, 학습자, 연습 시간, 코드 리뷰 여부가 확인 화면에 나옵니다.
   - 다음 상태: 3단계

7. 계획 저장
   - 행동: "계획 저장하기" 클릭
   - 이벤트: submit
   - 조건: 이미 저장 중인지, 제목이 조건에 맞는지
   - 저장 중 반응: 버튼이 "저장하는 중..."으로 바뀌고 비활성화됩니다.
   - 성공 반응: 약 0.6초 뒤 완료 화면이 나오고 내 계획 목록에 추가됩니다.
   - 오류 반응: localStorage에 저장하지 못하면 "저장하지 못했습니다. 입력 내용을 확인하고 다시 시도해 주세요."가 나오고 3단계에 머뭅니다.
   - 다음 상태: 완료 또는 다시 저장 시도

8. 새 계획 만들기
   - 행동: 완료 화면에서 "새 계획 만들기" 클릭
   - 이벤트: click
   - 조건: 없음
   - 화면 반응: 입력값, 글자 수, 안내 문구, 리뷰 항목 수 영역, 버튼이 처음 상태로 돌아갑니다.
   - 다음 상태: 1단계

## 실패 처리

localStorage를 사용할 수 없거나 저장 공간이 꽉 차면 실패로 처리했습니다. script.js의 savePlans()에서 저장에 실패하면 false를 반환하고, saveCurrentPlan()에서 방금 넣은 계획을 다시 뺍니다. 실패 문구는 submit 이벤트 안의 setTimeout에서 표시합니다.

## 확인 순서

1. 제목 없이 다음 버튼 누르기
2. 띄어쓰기만 넣거나 1자만 넣고 다음 버튼 누르기
3. 2자 이상으로 고쳐서 오류가 없어지는지 보기
4. AI 코드 리뷰를 체크했다가 해제해 보기
5. 저장을 눌러서 저장 중 문구가 나오고 버튼이 막히는지 보기
6. 완료 화면과 내 계획 목록 보기
7. 새 계획 만들기를 눌러서 모두 초기화되는지 보기

## 테스트 결과

크롬 headless에서 자동 검사를 돌려서 확인했고, 37개 항목 모두 통과했습니다.

1. 빈 값
   - 제목 없이 제출하면 1단계에 그대로 있고 "과제 제목을 입력해 주세요."가 나왔습니다.
   - 띄어쓰기만 넣어도 똑같이 막혔습니다.
2. 잘못된 값
   - 1자만 넣으면 "과제 제목은 2자 이상 입력해 주세요."가 나오고 제출이 막혔습니다.
3. 오류 수정
   - 2자로 고치면 오류가 없어지고 2단계로 넘어갔습니다.
4. 조건부 영역
   - 처음에는 리뷰 항목 수 영역이 숨겨져 있고 disabled 상태였습니다.
   - 체크하면 나타나고 해제하면 다시 숨겨졌습니다.
   - 3개를 고르고 넘어가면 확인 화면에 "리뷰 3개 포함"이 나왔습니다.
5. 저장 실패
   - localStorage에서 일부러 오류가 나게 하고 저장해 보니 3단계에 그대로 있고 실패 문구가 나왔습니다.
   - 제목은 그대로 남아 있었고 버튼도 다시 활성화됐습니다.
6. 정상 저장
   - 저장 중에 한 번 더 제출해도 계획은 1건만 저장됐습니다.
   - 완료 화면과 내 계획 목록에도 잘 나왔습니다.
7. 새 계획 만들기
   - 누르면 입력값과 문구, 버튼이 전부 처음 상태로 돌아가고 1단계로 이동했습니다.
